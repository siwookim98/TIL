### Ajax
Asynchronous JavaScript and XML
비동기적인 웹 애플리케이션 개발을 위한 기술
현대 웹의 핵심 기술 중 하나
웹 페이지 전체를 새로고침하지 않고 서버와 데이터를 주고받는 비동기 통신 기술
좋아요를 눌렀을 때 페이지만 부분적으로 바뀌는 것이 가능
구글 지도 앱을 움직여도 끊김이 없고

#### Ajax 정의
XML HttpRequest
브라우저와 서버 간의 데이터를 비동기적으로 교환하는 기술
페이지 전체를 새로고침하지 않고
JSON 형식

#### Ajax 목적
1. 비동기 통신
2. 부분 업데이트
3. 서버 부하 감소

#### 기존 기술과의 차이 (2)
form을 채우고 이를 서버로 제출(submit)
새로운 웹페이지를 작성하여 응답으로 전달
새로운 페이지를 응답 받기 때문에 새로고침이 발생
필요한 부분에 대한 데이터마 처리 후 응답
기존 페이지의 일부를 수정 (새로고침 X)
교환되는 데이터양이 줄어듦
