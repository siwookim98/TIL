### 변수 작성 규칙
gitlab으로 진행
! + tab으로 index.html 구조
option + cmd + i로 크롬 개발자도구

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <h1>Heading 1</h1>

    <script>
        console.log('Hello js')

        // // let 키워드
        // let number = 10
        // console.log(number)
        // number = 20 // 재할당이 가능하다
        // console.log(number)
        // // let number = 30 // 재선언 불가

        // const 키워드
        const number = 10
        console.log('const', number)
        number = 20 // 재할당 불가 (TypeError)
        console.log(number)

        // 3. block scope
        // - 중괄호({}) 안에서 let, const로 선언한 변수는 중괄호 밖에서 보이지 않음
        let x = 1
        if (x === 1) {
          let x = 2
          console.log('in', x) // 2 (블록 안의 x)
        }
        console.log('out', x) // 1 (블록 밖의 x)

        // => 기본은 const, 재할당이 꼭 필요할 때만 let
    </script>
</body>
</html>
```
#### 식별자(변수명) 작성 규칙
문자, $, _로 시작
for, if, function 등 예약어 사용 불가
이름을 사용하여 데이터의 의미를 명확히 설명

#### 식별자(변수명) Naming Convention
카멜 케이스(camelCase) - userName

### 변수 선언 키워드
const를 기본으로 사용할 것
해당 변수가 재할당되지 않을 것임을 표현
의도치 않은 변수 값 변경으로 인한 버그를 예방
